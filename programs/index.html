THE PRINCIPLE

AI does not get the final vote.

Zybot can organise, evaluate, test, and prepare a draft. People decide what deserves to be built. Community interest is a signal—not proof that an idea is scientifically correct.

WHAT HAPPENS NEXT?

  1. IntakeYour suggestion becomes a labelled GitHub Issue.
  2. EvaluationZybot checks clarity, educational value, feasibility, references, and safety.
  3. DraftFor eligible ideas, Zybot prepares a clearly marked starter prototype and an implementation brief in a Pull Request.
  4. ReviewThe maintainer reviews, edits, requests changes, or closes it. Zybot cannot merge or publish it.
Important

Do not submit passwords, personal details, copyrighted source code you do not own, or instructions for harmful activity. Submissions are public. Zybot treats every submission as untrusted text.
