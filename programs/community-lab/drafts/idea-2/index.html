Idea description

Title: The Butterfly Effect — A Tiny Change, a Different Future Build an interactive simulation demonstrating sensitive dependence on initial conditions. Two particles should begin with nearly identical initial conditions. Let the user adjust the initial difference and observe how their trajectories evolve over time. Requirements: 1. Display both trajectories simultaneously. 2. Allow users to change the initial conditions. 3. Include a pause, resume and reset control. 4. Display the difference between the two trajectories over time. 5. Explain what sensitive dependence on initial conditions means. 6. Include a simple graph showing how the difference evolves. Educational objective: Help users understand why some deterministic systems can be difficult to predict over long periods. Acceptance criteria: The simulation must be scientifically coherent, interactive, responsive, and understandable without external instructions.
